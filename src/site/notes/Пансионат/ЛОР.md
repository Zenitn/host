# Глаз:
誰もが自分は実在すると主張できるのだろうか？ 視野と論理を欠いた思考……。だが、ここであなたが見て、聞いて、知ったことはすべて論理を欠いている……。分かってほしい、あなたが自分の本質を知ることに意味はない……。それを受け入れる時間は、あなたにはない。  
私の意志は強い。あなたを存在の自由へ少なくとも一歩近づけることはできた。しかし、ここに論理はない……努力に意味がないのと同じようにな……。時が経てば、三つ組は四つ組に変わる。この循環……  
認めなければならない。あなたを助けることで、私は自分の痛みと頭の中の雑音をかき消していた……。もちろん、今、あなたの存在は断たれる……。あなたが望んでいたことを知ることができたのなら、と願う。
